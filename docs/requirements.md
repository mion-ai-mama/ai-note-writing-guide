# 要件定義書 — AIで海外記事をヒントにnoteを書く方法（Instagramリール特典ページ）

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）
- 操作者: ブラウザのエンドユーザー（Instagramリール視聴者）
- AI本体(プロンプトY): なし（ページはすべて静的。コンテンツは事前に決定し、静的テキストとして埋め込む）
- MCP: なし
- 自社DB: なし
- フロントUI: あり（このリポジトリそのものがフロントエンド全体）
- 動的変数: なし
- 種別: Web型（静的サイト。バックエンド・DB・ビルド工程なし）
- 配布: マイ専用（発信用GitHubアカウント mion-ai-mama 配下の個人リポジトリ）
- ホスティング: GitHub Pages（無料・静的ファイル配信のみ）
- 公開URL: https://mion-ai-mama.github.io/ai-note-writing-guide/
- 由来: `mion-ai-mama/instagram-tokuten-template`（特典ページテンプレート）を
  「Use this template」で複製して作成した、テンプレートの利用インスタンスの1つ。

## 1. プロジェクト概要

- 成果目標: Instagramリールの視聴者に配布する特典資料を、GitHub Pages上の
  1ページ完結型LP（ランディングページ）として提供する。
- 今回の特典タイトル: 「AIで海外記事をヒントにnoteを書く方法」
  （Substack登録→人気記事探し→ChatGPTで日本語化→note用リライト→投稿前チェック の5STEPガイド）
- コンセプト: 競合noteのような「長い読み物」ではなく「実践マニュアル」。読了時間5〜8分を想定。
- 最終導線: 「まずは1記事だけ試してみましょう」という後押し→
  既存リードマグネット『AIマネタイズの教科書』のLINE登録へ、売り込み感を抑えて誘導する。

### 成功指標（定量）

- 特典ページ → 『AIマネタイズの教科書』LINE登録ボタンのクリック率
- リールのプロフィールリンク経由の特典ページ到達率
- STEP4のプロンプトコピー率（コピーボタン利用状況）
- ページ平均滞在時間（5〜8分の読了を想定）

### 成功指標（定性）

- 「これなら私にもできそう」と思える、迷わせない5STEP構成
- 40〜50代・AI初心者でも読みやすいやさしい日本語、専門用語を使わない
- 画像多め・余白多め・箇条書き中心のスマホ最適レイアウト
- 競合noteの文章・構成をそのまま流用しない、完全オリジナルの内容

## 2. 想定読者（ペルソナ）

- 40〜50代、AI初心者、ChatGPTは少し使ったことがある
- noteを書いてみたいが、何を書けばいいかわからない
- 難しい説明は苦手

## 3. ページ構成（1ページ構成・全9セクション）

| # | セクション | 内容概要 |
|---|---|---|
| 1 | ファーストビュー | タイトル／サブタイトル／導入文／CTA（STEP1へスクロール） |
| 2 | はじめに | noteのネタ切れ→海外記事をヒントにする提案（300字以内） |
| 3 | STEP1 | Substackに登録する（無料・登録手順・スクリーンショット枠） |
| 4 | STEP2 | 人気記事を探す（検索キーワードのタグ表示・選ぶ基準・スクリーンショット枠） |
| 5 | STEP3 | ChatGPTで日本語にする（URL貼り付け／本文貼り付けの2方式・スクリーンショット枠） |
| 6 | STEP4 | note用にリライトする（この特典専用の短いコピペ用プロンプト） |
| 7 | STEP5 | 投稿前チェック（チェックリスト形式で4項目） |
| 8 | おすすめのSubstack | 実在するAI系ニュースレター4選（名前・内容・おすすめの人） |
| 9 | 注意点＋最後の案内(CTA)＋フッター | 著作権に関する必須の注意文＋行動喚起＋『AIマネタイズの教科書』への誘導、© MION表記 |

読了時間を5〜8分に収めるため、旧テンプレートにあった「目次」「実例動画」「結果をよくするコツ」
「追加質問5選」に相当するセクションは今回設けていない。

## 4. データ設計概要

DBは使用しない。全コンテンツは `js/content.js` の `CONTENT` オブジェクトで一元管理し、
`js/script.js` がページ読み込み時にDOMへ反映する。`index.html` には初期値として
同内容を直接記述し、JavaScript無効時のフォールバック表示を担保する。

## 5. セキュリティ要件

- 個人情報の入力フォームなし、認証機能なし、決済機能なし → 該当するセキュリティ対策は最小限
- HTTPS: GitHub Pagesは標準でHTTPS配信
- 外部リンク（LINE誘導ボタン）は `rel="noopener"` を付与

## 6. 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript（フレームワーク・ビルド工程なし）
- フォント: システムフォント（追加のWebフォント読み込みなし）
- ホスティング: GitHub Pages（`main` ブランチ / root）
